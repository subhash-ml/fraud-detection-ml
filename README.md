# Credit Card Fraud Detection using Machine Learning

##  Project Overview
In this project, I worked on detecting fraudulent credit card transactions using machine learning techniques. I analyzed transaction data and built models to identify suspicious patterns and anomalies.



##  Dataset Information
- Dataset: Credit Card Transactions
- Total Records: ~28,000+
- Features: V1 to V28 (PCA transformed), Time, Amount
- Target: Class (0 = Normal, 1 = Fraud)



##  Techniques Used
- Data Preprocessing
- Feature Scaling (StandardScaler)
- Dimensionality Reduction (PCA)
- Clustering (K-Means)
- Anomaly Detection (Isolation Forest)



##  Project Workflow

1. Data Loading and Exploration
2. Checking missing values (No null values found)
3. Feature scaling using StandardScaler
4. Applying PCA for dimensionality reduction
5. Finding optimal clusters using Elbow Method
6. Clustering using K-Means
7. Fraud detection using Isolation Forest
8. Visualization using PCA components



##  Results
- Successfully identified anomalies in transaction data
- Used Isolation Forest for fraud detection
- Visualized fraud vs normal transactions using PCA
- Silhouette Score: ~0.067 (indicates clustering performance)
